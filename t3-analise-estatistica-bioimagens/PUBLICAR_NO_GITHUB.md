# Publicação no GitHub pela interface do navegador (Windows)

1. Entre em <https://github.com/new> com sua conta.
2. Em **Repository name**, informe `t3-analise-estatistica-bioimagens`.
3. Em **Description**, escreva: `Reprodução de testes estatísticos em imagens biomédicas com R (Segebarth et al., 2020)`.
4. Selecione **Public**. Não marque **Add a README file**, **Add .gitignore** ou licença:
   estes materiais já fazem parte da pasta fornecida.
5. Clique em **Create repository**.
6. Na página do repositório vazio, escolha **uploading an existing file**
   (ou **Add file → Upload files**).
7. **Extraia o ZIP preparado**, abra a pasta interna `t3-analise-estatistica-bioimagens`
   e arraste **os arquivos e a pasta `resultados_exemplo` de dentro dela** para a área de upload.
   Não envie o arquivo ZIP como um arquivo isolado nem duplique uma pasta com o nome do repositório.
8. Finalize em **Commit changes**. Confira se o README aparece na página inicial.
9. Copie o URL definitivo, que terá a forma
   `https://github.com/SEU_USUARIO/t3-analise-estatistica-bioimagens`.
10. Atualize o relatório acadêmico com o URL real e cite separadamente o artigo
    original de Segebarth et al. (2020).

Caso a interface não envie o `.gitignore` oculto pelo Explorador do Windows,
crie esse arquivo diretamente pelo GitHub: **Add file → Create new file**,
colando o conteúdo da versão fornecida.

**Atenção:** não compartilhe arquivos pessoais, senhas, credenciais ou capturas
contendo informações que não queira tornar públicas.
