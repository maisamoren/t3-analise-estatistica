# Como citar este repositório no relatório

A principal referência científica continua sendo o artigo de
**Segebarth et al. (2020)** e seu material suplementar. Este repositório
identifica a implementação utilizada para reproduzir os testes.

## Texto sugerido

> O código de preparação dos dados, os procedimentos de análise estatística e as
> instruções necessárias à reprodução dos resultados encontram-se disponíveis
> em um repositório público no GitHub (INSERIR URL). Os dados quantitativos
> foram obtidos do material suplementar *Figure 5 — Source Data 1* de
> Segebarth et al. (2020).

## Exemplo de referência BibTeX — preencher depois de publicar

```bibtex
@misc{reproducaoT3_2026,
  author = {SEU NOME COMPLETO},
  title = {Reproducao de analises estatisticas em imagens biomedicas},
  year = {2026},
  howpublished = {Repositorio GitHub},
  url = {https://github.com/SEU_USUARIO/t3-analise-estatistica-bioimagens},
  note = {Codigo-fonte em R e instrucoes de reproducao}
}
```

**Não adicione essa referência sem substituir os campos de exemplo.**
Caso o repositório seja atualizado depois da entrega, indique o identificador
do commit ou uma versão estável na referência, para que a análise permaneça
reproduzível.
